    12 OI Reference¶

    12.1 Navigation¶

    The Depositor OI presents information across three regions: a fixed header at the top, a fixed navigation bar at the bottom, and a main screen area that changes based on the selected button. The header and navigation bar remain visible on every screen.

    12.1a Header¶

    Display Description
    ACTIVE RECIPE Recipe number and name currently loaded.
    CURRENT USER Active login level.
    STATUS BANNER Banner reflecting the current Depositor state. See Section 12.9: Depositor Status Banner.
    DATE AND TIME Current system date and time.
    SCREEN TITLE Text identifying the currently active screen.

    12.1b Navigation Bar¶

    Control Description
    HOME Navigates to the HOME screen.
    RECIPE Navigates to the RECIPE screen.
    MANUAL Navigates to the MANUAL screen.
    ALARMS Navigates to the ALARMS screen.
    MAINT Navigates to the MAINT screen.
    LANGUAGE SWITCH Toggles the OI language between English and Spanish.
    BACK Returns to the previous screen.

    12.2 HOME Screen¶

    The HOME screen is the primary operating screen. It provides Depositor start and stop controls, operating mode selection, and target delay fine-tuning. See Section 4: Operating Modes and Section 6.3: Target Tracking.

    Group Description
    MACHINE CONTROL MACHINE ENABLE is a physical pushbutton on the OI enclosure that arms the safety circuit. PRESS TO START and PRESS TO STOP are OI buttons that initiate and stop the selected operating mode. LOCAL / REMOTE selects the control source. See Section 3: Startup.
    OPERATING MODE Selects the operating mode. See Section 4: Operating Modes.
    TARGET DELAY ADJUST FINE and COARSE buttons adjust TARGET DELAY in the active recipe. See Section 6.3.
    SKIP MODE SKIP MODE indicator shows when active. SYNC shifts the skip phase by one target. See Section 5.3: Skip Mode.

    12.3 RECIPE Screen¶

    The RECIPE screen provides recipe management. Editable fields have a yellow background with green text. See Section 5: Recipe Setup and Appendix A: Recipe Starting Points.

    Group Description
    RECIPE FIELDS All production parameters. See Section 5.1: Recipe Screen Field Reference.
    RECIPE MANAGEMENT Load and save recipes. See Section 5.2: Loading and Saving Recipes.

    12.4 MANUAL Screen¶

    The MANUAL screen provides access to individual drive service screens, diagnostic screens, direct equipment controls, and the WIPEDOWN screen.

    Group Description
    VFD DRIVES PRODUCT CONVEYOR, RAKE, and SPINNER. FEED-Z, AUX 1, and AUX 2 when equipped. Each drive opens a detail screen showing manual control, current, and last fault.
    SERVO DRIVES CARPET, PORTION CONVEYOR, and FEED CONVEYOR (bidirectional, when equipped). Each drive opens a detail screen with JOG + and JOG -, fault info, current and position display, and status (READY, FAULTED, HOMED).
    DIAGNOSTIC NAVIGATION Navigation to the TARGET PHOTO EYE remote setup, SAFETY PLC, and I/O STATUS screens.
    BUCKET Direct manual toggle for the BUCKET.
    STACKLIGHT Direct manual toggle for the STACKLIGHT. See Section 12.10: STACKLIGHT Reference.
    WIPEDOWN Opens a blank screen with no active buttons, so the operator can wipe down the OI without triggering a control.

    12.5 ALARMS Screen¶

    The ALARMS screen logs active and historical alarm events. For fault descriptions and corrective actions, see Section 13: Troubleshooting.

    Group Description
    ALARM SUMMARY Timestamped list of alarm events.
    CLEAR ALARM LIST Clears the alarms in the alarm banner.
    FAULT RESET Resets latched system faults.
    UP/DOWN BUTTONS Alarm banner up/down navigation.

    Note

    State Appearance
    Active Red background, white text.
    Inactive White background, black text.
    Selected White background, red text.

    12.6 MAINT Screen¶

    The MAINT screen provides access to drive configuration, calibration, and system settings.

    Group Description
    MOTOR SETUP Drive scaling and limit configuration. See Section 12.7: Motor Setup Screens.
    CALIBRATIONS Load cell calibration. See Section 12.8: Calibration Screens.
    MACHINE OPTION LEFT-RIGHT HAND sets the Depositor's feed orientation. FEED-Z / NO FEED-Z enables or disables the FEED-Z CONVEYOR option. SKIP MODE ENABLE / DISABLE enables or disables Skip Mode. RESET HISTORY clears stored production history. DATE/TIME sets the system clock.
    TRACKING MODE Selects Time-Based or Encoder-Based target tracking. See Section 6.3: Target Tracking.
    SPARE OUTPUT SELECTION Assigns spare output points.
    TARGET TEST MODE Runs the deposit cycle automatically without a TARGET SENSOR input, for testing without product on the conveyor.

    12.7 Motor Setup Screens¶

    Each drive has a dedicated Motor Setup screen. See Section 7: Motor Speed Scaling, Section 8: Kollmorgen Servo Setup, and Section 9: Linmot Servo Setup.

    Drive Reference
    PRODUCT CONVEYOR / RAKE / SPINNER (FEED-Z, AUX 1, AUX 2 when equipped) Section 7
    PORTION CONVEYOR / FEED CONVEYOR Section 8
    CARPET Section 9

    12.8 Calibration Screens¶

    Group Description
    LOAD CELL SETUP Captures MIN and MAX calibration points for the PORTION CONVEYOR HOPPER LOAD CELL and the FEED CONVEYOR HOPPER LOAD CELL (Option). See Section 10: Load Cell Calibration.

    Note

    The CARPET is a servo actuator and does not require calibration. Its homed status appears on its MANUAL
