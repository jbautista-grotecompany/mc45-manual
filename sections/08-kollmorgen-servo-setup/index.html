    8 Kollmorgen Servo Setup¶

    8.1 Overview¶

    The PORTION CONVEYOR and FEED CONVEYOR use Kollmorgen AKD servo drives over EtherNet/IP. Each drive has a dedicated setup screen on the OI, reached from MAINT → MOTOR SETUP → [drive name].

    The PORTION CONVEYOR setup screen allows the operator to adjust the move profile used to advance topping toward the BUCKET. The FEED CONVEYOR setup screen is read-only. It displays the belt speed calculated from the conveyor shaft size and gear ratio.

    8.2 PORTION CONVEYOR Move Profile¶

    The PORTION CONVEYOR advances in a trapezoidal move: it accelerates to a peak velocity, then decelerates to a stop. The move must complete within the time available between targets, which depends on MACHINE RATE.

    MACHINE RATE is the number of targets processed per minute. A higher MACHINE RATE leaves less time for the PORTION CONVEYOR to complete its move between targets.

    MOVE LENGTH is the fixed distance the belt advances each cycle, set elsewhere in the active recipe.

    ACCEL RATE sets how quickly the belt reaches peak velocity, in inches per second squared (in/sec²). The PLC uses MACHINE RATE, MOVE LENGTH, and ACCEL RATE together to calculate the peak velocity needed to complete the move in the time available.

    DECEL RATE sets how quickly the belt slows down after reaching peak velocity, in the same units.

    Both ACCEL RATE and DECEL RATE are limited to a range of 10 to 500 in/sec². Values outside this range are rejected by the OI.

    Note

    ACCEL RATE determines the calculated PEAK SPEED and MOVE TIME shown below. DECEL RATE does not change these calculated values. Increasing DECEL RATE does not shorten the overall move.

    Note

    The PORTION CONVEYOR is a positive pin-drive belt. Setting ACCEL RATE too high can cause the belt to skip on the drive pins. If skipping occurs, reduce ACCEL RATE and retest.

    Portion Conveyor Move Profile
    Adjust MACHINE RATE, MOVE LENGTH, and ACCEL RATE to see the resulting velocity profile.
    MACHINE RATE (targets/min) 48
    MOVE LENGTH (in) 5.0
    ACCEL RATE (in/sec²) 50
    DECEL RATE (in/sec²) 50 (informational, not used in calculation below)

    8.3 FEED CONVEYOR Belt Speed Display¶

    The FEED CONVEYOR setup screen is read-only. It does not accept an ACCEL RATE or DECEL RATE, since the FEED CONVEYOR runs at a continuous speed rather than a fixed-distance move.

    The screen displays a calculated belt speed in FPM, derived from two fixed values entered during commissioning: the conveyor shaft (roller) diameter and the gear ratio between the motor and the shaft. These two values do not change during normal operation and are set once when the Depositor is commissioned or when the motor or gearbox is replaced.

    The shaft diameter determines how far the belt travels for each shaft rotation. A larger shaft moves more belt per rotation. The gear ratio determines how many motor rotations produce one shaft rotation. A higher gear ratio means the motor spins faster relative to the shaft. Combining these two values with the motor's actual rotation speed gives the belt's linear speed, which the screen displays in FPM.

    Adjust shaft diameter, gear ratio, and motor speed to see the resulting belt speed.

    Gear Ratio (motor : shaft) 10 : 1
    Motor Speed (RPM) 1200
