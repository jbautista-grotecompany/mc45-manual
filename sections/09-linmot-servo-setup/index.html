    9 Linmot Carpet Servo Setup¶

    9.1 Overview¶

    The CARPET is driven by a Linmot C1250 linear servo. Its setup screen is reached from MAINT → MOTOR SETUP → CARPET and allows the operator to adjust the extend and retract move profile.

    The CARPET does not run at a fixed velocity. As described in Section 6.2, CARPET speed during the extend move is set by EXTEND RATIO, a multiplier applied to PRODUCT CONVEYOR speed. An EXTEND RATIO of 1.0 moves the CARPET at the same speed as the PRODUCT CONVEYOR. An EXTEND RATIO of 0.5 moves the CARPET at half that speed.

    Four parameters are adjustable from this screen: EXTEND RATIO, ACCEL RATE, DECEL RATE, and MOVE TYPE. MOVE TYPE selects between a TRAPEZOIDAL move and an S-CURVE move. When S-CURVE is selected, a fifth parameter, JERK, becomes available.

    ACCEL RATE and DECEL RATE are limited to a range of 50 to 1500 in/sec². JERK is limited to a range of 50 to 1500 in/sec³. Values outside these ranges are rejected by the OI.

    9.2 Trapezoidal Move¶

    A trapezoidal move accelerates the CARPET at a constant rate to the velocity set by PRODUCT CONVEYOR SPEED and EXTEND RATIO, then decelerates at a constant rate back to a stop. Acceleration changes instantly at the start and end of each phase. This produces the shortest possible move time for a given velocity, ACCEL RATE, and DECEL RATE, but the abrupt change in acceleration at each transition places a sudden mechanical load on the CARPET belt and its mounting hardware.

    Adjust PRODUCT CONVEYOR SPEED and EXTEND RATIO to set velocity, then adjust ACCEL RATE and DECEL RATE.

    EXTEND RATIO 1.00

    9.3 S-Curve Move¶

    An S-curve move reaches the same velocity as a trapezoidal move, but the acceleration itself ramps up and down smoothly instead of stepping instantly. JERK sets how quickly acceleration is allowed to change. A low JERK value produces a gradual, rounded acceleration ramp. A high JERK value approaches the sharp, instant transitions of a trapezoidal move.

    This smoother acceleration transition reduces the sudden mechanical shock transferred to the CARPET belt at the start and end of each move phase, at the cost of a slightly longer total move time compared to a trapezoidal move with the same velocity, ACCEL RATE, and DECEL RATE.

    Note

    JERK is only used and displayed when MOVE TYPE is set to S-CURVE. When MOVE TYPE is set to TRAPEZOIDAL, JERK has no effect.
