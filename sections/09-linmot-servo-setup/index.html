    9 Linmot Carpet Servo Setup¶

    9.1 Overview¶

    The CARPET is driven by a Linmot C1250 linear servo. Its setup screen is reached from MAINT → MOTOR SETUP → CARPET and allows the operator to adjust the extend and retract move profile.

    The CARPET does not run at a fixed velocity. As described in Section 6.2, CARPET speed during the extend move is set by EXTEND RATIO, a multiplier applied to PRODUCT CONVEYOR speed. An EXTEND RATIO of 1.0 moves the CARPET at the same speed as the PRODUCT CONVEYOR. An EXTEND RATIO of 2.0 moves the CARPET at twice that speed. The return stroke always runs at three times the extend velocity.

    Four parameters are adjustable from the extend profile: EXTEND RATIO, ACCEL RATE, and DECEL RATE. The return profile has its own ACCEL RATE and DECEL RATE. MOVE TYPE selects between a TRAPEZOIDAL move and an S-CURVE move for both strokes. When S-CURVE is selected, a fifth parameter, JERK, becomes available.

    ACCEL RATE and DECEL RATE are limited to a range of 50 to 1500 in/sec². JERK is limited to a range of 50 to 1500 in/sec³. Values outside these ranges are rejected by the OI.

    9.2 Trapezoidal Move¶

    A trapezoidal move accelerates the CARPET at a constant rate to the target velocity, cruises at that velocity if stroke length allows, then decelerates to a stop. If the stroke is too short to reach target velocity, the move peaks below it and produces a triangular profile. Acceleration changes instantly at each phase transition, placing a sudden mechanical load on the CARPET belt and mounting hardware.

    9.3 S-Curve Move¶

    An S-curve move reaches the same velocity as a trapezoidal move, but the acceleration itself ramps up and down smoothly instead of stepping instantly. JERK sets how quickly acceleration is allowed to change. A low JERK value produces a gradual, rounded acceleration ramp. A high JERK value approaches the sharp, instant transitions of a trapezoidal move.

    This smoother acceleration transition reduces the sudden mechanical shock transferred to the CARPET belt at the start and end of each move phase, at the cost of a slightly longer total move time compared to a trapezoidal move with the same velocity, ACCEL RATE, and DECEL RATE.

    Note

    JERK is only used and displayed when MOVE TYPE is set to S-CURVE. When MOVE TYPE is set to TRAPEZOIDAL, JERK has no effect.
